Visualization — 02

"사각의중의사각"
— 차원 상승의 구조

「AU MAGASIN DE NOUVEAUTES」의 첫 구절은 단순한 중첩이 아니다. 사각형 정중앙에 새 사각형을 직각으로 결합할 때마다 공간의 차원이 높아진다. 버튼을 눌러 이상이 시 속에 숨긴 차원 확장 과정을 확인해보라.

사각형 중심 결합과 차원 상승
현재: 1개의 사각형 — 2차원 평면

Visualization — 03

"스펙트럼" — 빛으로 차원을 열다

「각서 1」의 도식은 다양한 색의 빛나는 점들로 이루어진 2차원 격자다. 분광기가 빛을 파장별로 분해하듯, 각 점의 스펙트럼을 새로운 Z축으로 펼치면 2차원 격자가 3차원 공간으로 확장된다. 이것이 이상의 '차원 확장 장치'다.

각서 1의 도식 — 스펙트럼을 통한 2D → 3D 확장
슬라이더를 움직여 빛의 스펙트럼이 Z축으로 펼쳐지는 과정을 보라. (자동 재생 중)
2D 격자 (스펙트럼 숨김)3D 확장 (스펙트럼 전개)

Visualization — 04

4차원 초입방체
— 무한육면각체의 그림자

4차원 도형은 직접 볼 수 없다. 3차원 정육면체가 2차원 종이에 투영될 때 형태가 뒤틀리듯, 4차원 초입방체(tesseract)를 3차원으로 투영하면 이상하고 아름다운 형태가 나타난다. 이것이 이상이 설계한 '무한육면각체'의 그림자다. 각 꼭짓점에서 6개의 면이 만나는 구조가 바로 '육면각(六面角)'이다.

Tesseract — 4차원 초입방체의 3D 투영 (실시간 회전)
■ 3D 엣지    ■ W축 엣지 (4번째 차원)    ● 꼭짓점 — 각 꼭짓점에 6개의 면이 만남 = 육면각

Conclusion — 05

이상이 남긴 것

이상은 1930년대에 이미 문학·수학·물리학의 융합을 실천했다. 그의 시어는 문학적 언어인 동시에 수학적 개념이었고, 시의 형식 자체가 4차원을 향한 실험이었다. 예술적 감수성과 과학적 소양을 하나로 녹인 이상의 실험은 지금 더욱 유효하다.

01
삼차각 = 4차원 각도
초구면좌표계에서 방향을 기술하는 세 각도값 (ψ, φ, θ). 이상이 직접 만든 조어.
02
육면각 = 4D 꼭짓점
4차원의 가장 단순한 도형에서 한 꼭짓점에 만나는 6개의 면이 이루는 초입체각.
03
무한육면각체 = 시간 속 궤적
4차원 시공간 위의 임의의 도형. 시간에 따라 변화하는 3차원 물체의 전체 이야기.
04
스펙트럼 = 차원 확장 장치
각서 1의 도식에서 빛의 분광이 Z축을 생성, 2D → 3D 확장을 구현하는 시적 기법.
05
사각형 중심 결합 = 또 다른 장치
"사각의중의사각..." 구절이 직각 결합을 반복하며 2D→3D→4D를 달성하는 구조.
06
이상 = 융합의 원형
과학적 소양과 예술적 감수성을 하나로 녹인 이상의 실험은 지금 더욱 유효하다.
